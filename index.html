ClinicTabi

AI-enhanced healthcare management and triage platform

A multi-tenant healthcare platform that streamlines clinic registrations, physician workflows and patient assessments. An automated risk-triage engine categorizes patient severity in real time and manages follow-up protocols on a secure, serverless architecture.

  • Automated triage: built a risk-severity engine (High, Moderate, Emerging, Low) that scores assessments and instantly triggers tailored clinical guidance and patient emails.
  • Follow-up loop: an admin-controlled scheduler tracks recovery timelines and sends secure, time-limited assessment links in one click.
  • Clinical reports: server-side PDF generation with dynamic charts and physician-curated guidance notes.
  • Multi-tenant admin: role-based access control for Super Admins and Clinic Admins covering clinics, staff accounts and patient data.
  • Secure authentication: registration, multi-user clinics and password recovery by email through Azure Communication Services.
  • Cloud migration: the platform started on Azure Functions and Cosmos DB and was later migrated to Google Cloud, using Firebase Hosting, Firebase Functions and a Firebase database.

TBI Assessment Application

Three connected apps with an OpenAI conversational interface

A suite of applications for TBI-related assessments: a user-driven assessment app, a portal for law firms and a corporate wellness platform. The front end is built in Next.js, with Azure serverless functions and Cosmos DB behind it.

The chat interface uses OpenAI APIs for text and audio in both directions, with text-to-speech, speech-to-text and text-to-avatar speech, so a personalized avatar can speak the assessment content.

  • User Assessment App: users answer AI-driven prompts, and a full report is generated on completion and emailed to them.
  • Law Firm Portal: firms manage users, add clients, send assessments to TBI-affected individuals and read detailed reports and summaries.
  • Wellness Corporation Portal: wellness companies manage employee assessments and send targeted ones by group and location.
  • Cloud migration: the suite started on Azure Functions and Cosmos DB and was later migrated to Google Cloud, using Firebase Hosting, Firebase Functions and a Firebase database.
